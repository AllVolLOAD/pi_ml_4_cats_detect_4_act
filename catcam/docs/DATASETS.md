# Готовые датасеты для детекции кошек

## 🎯 Для чего нужны готовые датасеты

**Текущая ситуация:**
- YOLOv8n предобучена на COCO (80 классов, включая "cat")
- Но предобучение **общее**, не специализировано под домашних котов
- Дальний план детектируется хуже (как мы наблюдали)

**Решение:**
1. ✅ Использовать готовые датасеты для улучшения базовой детекции
2. ✅ Дополнить своими данными для специфики вашей задачи

---

## 📦 Рекомендуемые датасеты

### 1. COCO Dataset (стандарт индустрии) ⭐

**Что это:**
- 330K изображений, 80 классов
- Класс "cat" присутствует
- Аннотации в формате COCO JSON
- **Бесплатно**, открытый лицензией

**Где взять:**
- Официально: https://cocodataset.org/#download
- Для детекции нужен: **2017 Train/Val images + annotations**

**Формат:**
- JSON аннотации (нужна конвертация в YOLO)
- Много классов, но можно отфильтровать только "cat"

**Плюсы:**
- Качественные аннотации
- Разнообразие сцен (домашние, уличные коты)
- Стандарт индустрии

**Минусы:**
- Большой размер (~20GB изображений)
- Нужна конвертация в YOLO формат
- Много "лишних" классов

**Как использовать:**

### 2. Roboflow Universe (проще всего) ⭐⭐⭐

**Что это:**
- Платформа с готовыми датасетами в YOLO формате
- Многие датасеты **бесплатны**
- Можно скачать сразу в нужном формате (YOLOv8)
- Есть датасеты специально для кошек

**Где искать:**
- https://universe.roboflow.com/
- Поиск: "cat detection", "animal detection"

**Примеры датасетов:**
- "Cat Detection Dataset" (разные авторы)
- "Pet Detection Dataset" (кошки + собаки)
- "Animal Detection" (разные животные)

**Плюсы:**
- ✅ Уже в YOLO формате - готов к использованию
- ✅ Небольшой размер (100-500 изображений обычно)
- ✅ Можно скачать одним кликом
- ✅ Бесплатно (многие датасеты)

**Минусы:**
- Качество зависит от автора датасета
- Меньше изображений, чем COCO

**Рекомендация:** начать отсюда! Проще всего интегрировать.

**Минусы:**

## 🔄 Стратегия использования

### Вариант A: Быстрый старт (рекомендуется)

1. **Скачать датасет с Roboflow Universe:**
   - Найти "Cat Detection Dataset" (YOLOv8 формат)
   - Скачать (обычно 100-500 изображений)
   - Поместить в `data/datasets/external/`

2. **Добавить свои данные:**
   - Записать 50-100 своих кадров с котом
   - Разметить только свои (Roboflow уже размечен)
   - Объединить датасеты

3. **Fine-tune YOLOv8:**
   - Предобучение: `yolov8n.pt` (COCO)
   - Тренировка: COCO + Roboflow + свои данные
   - Эпох: 50-100 (зависит от объема)

**Время:** 1-2 дня (разметка своих данных)

---

### Вариант B: Максимальное качество

1. **Скачать COCO:**
   - Train 2017 (118K изображений)
   - Отфильтровать только класс "cat" (~10-15K изображений)
   - Конвертировать COCO → YOLO формат

2. **Добавить свои данные:**
   - 200-500 своих кадров
   - Разметка всех своих кадров

3. **Fine-tune:**
   - Предобучение: `yolov8n.pt`
   - Тренировка: COCO (cat only) + свои данные
   - Эпох: 100-200

**Время:** 1-2 недели (скачивание, конвертация, разметка)

## 🛠️ Практические шаги (Roboflow)

### 1. Поиск датасета на Roboflow

1. Открыть https://universe.roboflow.com/
2. В поиске: `cat detection`
3. Выбрать датасет с:
   - ✅ YOLOv8 формат (или YOLOv5, конвертируется)
   - ✅ 100+ изображений
   - ✅ Бесплатный доступ
   - ✅ Хорошие отзывы/просмотры

### 2. Скачивание

1. Нажать "Download"
2. Формат: **YOLOv8**
3. Сохранить в: `catcam/data/datasets/external/roboflow_cat/`

### 3. Структура после скачивания

```
roboflow_cat/
├── train/
│   ├── images/
│   └── labels/
├── valid/
│   ├── images/
│   └── labels/
└── data.yaml  # Описание классов
```

### 4. Интеграция со своими данными

catcam/data/datasets/combined/
├── train/

│   ├── images/  # Roboflow + свои
