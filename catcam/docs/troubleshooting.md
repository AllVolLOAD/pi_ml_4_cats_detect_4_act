# Решение проблем CatCam

## Общие проблемы

### Система не запускается

**Проблема:** Ошибка импорта модулей

**Решение:**
```powershell
cd catcam/pc
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
```

---

### FFmpeg не найден

**Проблема:** `'ffmpeg' is not recognized`

**Решение:**
1. Скачайте FFmpeg: https://ffmpeg.org/download.html
2. Добавьте в PATH или разместите ffmpeg.exe в папке проекта
3. Проверка: `ffmpeg -version`

---

## Проблемы с Receiver

### Не удается подключиться к SRT потоку

**Проблема:** `[Receiver] Ошибка: не удалось открыть поток`

**Проверка:**
1. Убедитесь, что Raspberry Pi запущен и стрим активен:
   ```bash
   # На Pi
   sudo netstat -tulpn | grep 9000
   ```

2. Проверьте IP адрес Pi:
   ```bash
   # На Pi
   hostname -I
   ```

3. Проверьте подключение с PC:
   ```powershell
   # На PC
   ping <PI_IP>
   ```

4. Проверьте config.yaml:
   ```yaml
   srt:
     url: "srt://<PI_IP>:9000"  # Правильный IP?
   ```

**Решение:**
- Убедитесь, что firewall на Pi разрешает входящие соединения на порт 9000
- Проверьте, что SRT стрим запущен на Pi
- Попробуйте другой порт

---

### Низкий FPS приема

**Проблема:** FPS приема ниже ожидаемого

**Причины:**
- Проблемы с сетью (пакетные потери)
- Перегрузка CPU на Pi
- Недостаточная пропускная способность сети

**Решение:**
- Уменьшите разрешение или FPS на Pi (в stream_cam.sh)
- Проверьте сетевую задержку: `ping <PI_IP>`
- Используйте проводное подключение вместо WiFi

---

## Проблемы с AI Detector

### Модель не загружается

**Проблема:** `[AI] Ошибка загрузки модели`

**Решение:**
- Модель будет автоматически загружена при первом запуске (yolov8n.pt)
- Проверьте подключение к интернету для первой загрузки
- После загрузки модель сохраняется локально

---

### GPU не используется

**Проблема:** `[AI] Используется устройство: cpu`

**Решение:**
1. Убедитесь, что установлен PyTorch с CUDA:
   ```powershell
   pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118
   ```

2. Проверьте доступность CUDA:
   ```python
   import torch
   print(torch.cuda.is_available())
   ```

3. Установите NVIDIA драйверы

---

### Кот не детектируется

**Проблема:** AI не находит кота

**Решение:**
1. Проверьте confidence threshold в config.yaml:
   ```yaml
   ai:
     confidence_threshold: 0.4  # Попробуйте уменьшить до 0.3
   ```

2. Проверьте, что класс правильный:
   ```yaml
   ai:
     class_filter: ["cat"]  # YOLOv8 использует "cat"
   ```

3. Тестируйте на отдельном изображении:
   ```powershell
   python ai_detector.py --image path/to/cat_image.jpg
   ```

4. Убедитесь, что кадры нормального качества (не слишком темные/размытые)

---

### Низкая скорость детекции

**Проблема:** AI обрабатывает < 5 fps

**Решение:**
- Уменьшите входное разрешение в config.yaml:
  ```yaml
  ai:
    input_width: 640   # Попробуйте 416
    input_height: 360  # Попробуйте 234
  ```
- Используйте GPU (см. выше)
- Используйте более легкую модель (yolov8n.pt уже самая легкая)

---

## Проблемы с Streamer

### Не удается подключиться к Twitch

**Проблема:** `[Streamer] Ошибка отправки кадра`

**Проверка:**
1. Убедитесь, что stream key правильный в config.yaml
2. Проверьте RTMP URL:
   ```yaml
   twitch:
     rtmp_url: "rtmp://live.twitch.tv/app/"
     stream_key: "live_xxxxxxxxxxxxx"  # Ваш ключ
   ```

3. Проверьте, что стрим активен в Twitch Dashboard

**Решение:**
- Получите новый stream key в Twitch Creator Dashboard
- Убедитесь, что URL и ключ правильные (без лишних пробелов)

---

### Низкое качество стрима

**Проблема:** Размытое/пикселизированное видео

**Решение:**
1. Увеличьте битрейт в config.yaml:
   ```yaml
   stream:
     bitrate: "3500k"  # Вместо 2500k
   ```

2. Используйте более медленный preset (лучшее качество):
   ```yaml
   stream:
     preset: "fast"  # Вместо "veryfast"
   ```
   (но это увеличит нагрузку на CPU)

---

### Задержка стрима

**Проблема:** Большая задержка между реальным временем и стримом

**Причины:**
- Twitch имеет встроенную задержку 2-5 секунд
- Буферизация в FFmpeg
- Сетевая задержка

**Решение:**
- Это нормально для RTMP стриминга
- Для снижения задержки используйте Twitch Low Latency mode
- Уменьшите буферы в FFmpeg (но это может привести к артефактам)

---

## Проблемы с Raspberry Pi

### Камера не определяется

**Проблема:** `/dev/video0 not found`

**Решение:**
```bash
# Проверка USB устройств
lsusb

# Проверка видео устройств
ls -l /dev/video*

# Если камера найдена, проверьте доступ
sudo chmod 666 /dev/video0
```

---

### Низкая производительность на Pi

**Проблема:** Высокая загрузка CPU, пропуски кадров

**Решение:**
1. Уменьшите разрешение в stream_cam.sh:
   ```bash
   WIDTH=640
   HEIGHT=480
   ```

2. Уменьшите FPS:
   ```bash
   FPS=15
   ```

3. Используйте более быструю SD карту (Class 10, U3)
4. Убедитесь, что Pi не перегревается (температура < 70°C)

---

### Стрим прерывается

**Проблема:** Периодические обрывы соединения

**Проверка:**
```bash
# На Pi - проверка сетевого интерфейса
ip addr show

# Проверка стабильности сети
ping -c 100 <PC_IP>
```

**Решение:**
- Используйте проводное подключение (Ethernet)
- Убедитесь в стабильности питания Pi (используйте качественный блок питания 5V 3A)
- Увеличьте latency в SRT (в stream_cam.sh и config.yaml)

---

## Проблемы с интеграцией

### Bbox не отображается в стриме

**Проблема:** AI детектирует, но рамка не рисуется

**Проверка:**
1. Убедитесь, что UDP работает:
   ```powershell
   # Включите вывод в ai_detector.py (print_result=True)
   # Проверьте, что bbox отправляется
   ```

2. Проверьте порты UDP:
   ```powershell
   netstat -an | findstr 5555
   ```

3. Убедитесь, что streamer запущен с --use-ai:
   ```powershell
   python streamer.py --use-ai
   ```

**Решение:**
- Убедитесь, что оба процесса (ai_detector и streamer) используют один порт UDP
- Проверьте firewall Windows (может блокировать UDP)

---

### Проблемы с синхронизацией

**Проблема:** Рамка не совпадает с положением кота

**Причина:**
- Разные разрешения для AI (640×360) и стрима (1280×720)
- Масштабирование координат

**Решение:**
- Это нормально, координаты масштабируются автоматически
- Если точность критична, используйте одинаковое разрешение для AI и стрима

---
