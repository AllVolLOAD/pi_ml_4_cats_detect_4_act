# Быстрый старт: Отправка файлов на малину и запуск

## Что нужно отправить на малину

После изменений в коде нужно отправить:

1. **`main.py`** - обновленный код
2. **`config.yaml`** - обновленный конфиг (если нужен)

**Путь на малине:** `/home/mlprojectcat/catcam/pc/`

## Быстрая отправка

Из папки `catcam/pc/`:

```powershell
.\scripts\push_to_pi.ps1
```

С автоматическим запуском сервиса:

```powershell
.\scripts\push_to_pi.ps1 -StartService
```

## Автоматический запуск сервиса на малине

Теперь при запуске `main.py` на PC **автоматически** запускается сервис на малине!

Это работает благодаря настройке в `config.yaml`:

```yaml
pi_service:
  enabled: true  # автоматически запускать сервис на малине при старте
  pi_host: "mlprojectcat@192.168.1.103"
  service_name: "cam-stream-record.service"
```

### Как это работает:

1. Запускаете `python main.py` на PC
2. Автоматически запускается `cam-stream-record.service` на малине
3. PC подключается к SRT потоку от малины
4. Начинается обработка видео

### Если нужно отключить автозапуск:

В `config.yaml` установите:

```yaml
pi_service:
  enabled: false
```

## Ручной запуск сервиса на малине

Если нужно запустить сервис отдельно:

```powershell
.\scripts\start_pi_service.ps1
```

## Проверка статуса сервиса на малине

```bash
ssh mlprojectcat@192.168.1.103
sudo systemctl status cam-stream-record.service
```

## Важно

- Для автоматического запуска нужен SSH доступ (настроить SSH ключи для входа без пароля)
- Если SSH ключи не настроены, при запуске может потребоваться ввод пароля
