# Архитектура CatCam системы

## Обзор

CatCam - система для стриминга видео с детекцией кота в реальном времени на Twitch. Система состоит из двух основных компонентов:

1. **Raspberry Pi** - захват и отправка видео потока через SRT
2. **Windows PC** - прием, обработка AI, наложение оверлея и стрим в Twitch

## Архитектурная диаграмма

```
┌─────────────────┐
│  Raspberry Pi   │
│                 │
│  USB Camera     │──┐
│       │         │  │
│   FFmpeg        │  │ SRT Stream
│   (encoder)     │──┘  (720p30)
│                 │
└─────────────────┘
         │
         │ Network (SRT)
         │
         ▼
┌─────────────────────────────────────────────┐
│           Windows PC                        │
│                                             │
│  ┌──────────────┐      ┌──────────────┐   │
│  │  Receiver    │─────▶│ AI Detector  │   │
│  │              │      │  (YOLOv8)    │   │
│  │  (SRT→frames)│      │              │   │
│  └──────┬───────┘      └──────┬───────┘   │
│         │                     │            │
│         │ frames              │ bbox       │
│         │                     │ (UDP JSON) │
│         ▼                     ▼            │
│  ┌──────────────────────────────────────┐ │
│  │         Streamer                     │ │
│  │                                      │ │
│  │  • Overlay (bbox)                    │ │
│  │  • FFmpeg encoding (x264)            │ │
│  │  • RTMP to Twitch                    │ │
│  └──────────────┬───────────────────────┘ │

                  │

                  ▼
         ┌─────────────────┐
         │  Twitch Server  │
         │                 │
         │  Live Stream    │
         └─────────────────┘
```

## Компоненты

### Raspberry Pi (Agent 1)

**Задачи:**
- Захват видео с USB камеры
- Кодирование H.264
- Отправка через SRT протокол

**Технологии:**
- FFmpeg для захвата и кодирования
- SRT для низколатентной передачи

**Параметры:**
- Разрешение: 1280×720
- FPS: 30
- Битрейт: 2 Mbps
- Preset: ultrafast (низкая задержка)

### PC Receiver (Agent 2)

**Задачи:**
- Прием SRT потока
- Декодирование видео
- Буферизация кадров
- Передача кадров в AI детектор и стример

**Технологии:**
- OpenCV (cv2.VideoCapture) для приема SRT
- Queue для буферизации кадров

**Параметры:**
- Буфер: ~60 кадров (2 секунды при 25 fps)
- Неблокирующая передача кадров

### AI Detector (Agent 3)

**Задачи:**
- Детекция кота на кадрах
- Фильтрация по confidence threshold
- Отправка bbox через UDP

**Технологии:**
- Ultralytics YOLOv8n (легкая модель)
- PyTorch (CUDA если доступен)
- UDP socket для передачи bbox

**Параметры:**
- Входное разрешение: 640×360 (оптимизация)
- Confidence threshold: 0.4
- Класс: "cat"
- Частота обработки: 5-10 fps (оптимизация)

**Протокол UDP JSON:**
```json
{
  "t": 1735720000.123,  // timestamp
  "bbox": [x1, y1, x2, y2],  // координаты или null
  "conf": 0.78  // confidence
}
```

### Streamer (Agent 4)

**Задачи:**
- Получение кадров от receiver
- Получение bbox от AI detector (через UDP)
- Наложение оверлея (прямоугольник + текст)
- Кодирование через FFmpeg
- Отправка в Twitch через RTMP

**Технологии:**
- OpenCV для рисования оверлея
- FFmpeg subprocess для кодирования
- UDP socket для приема bbox

**Параметры:**
- Разрешение выхода: 1280×720
- FPS: 25
- Битрейт: 2500 kbps
- Preset: veryfast (x264)

## Потоки данных

### 1. Видео поток (SRT)

```
Pi Camera → FFmpeg encoder → SRT → PC Receiver → Queue → Streamer
```

**Формат:** MPEG-TS over SRT
**Задержка:** ~200ms

### 2. AI данные (UDP)

```
AI Detector → UDP JSON → Streamer (overlay)
```

**Формат:** JSON через UDP
**Порт:** 5555 (по умолчанию)
**Частота:** 5-10 fps

### 3. Стрим (RTMP)

```
Streamer → FFmpeg encoder → RTMP → Twitch
```

**Формат:** FLV (H.264 + AAC)
**Задержка:** ~2-5 секунд (из-за Twitch)

## Производительность

### Raspberry Pi
- CPU использование: ~30-50%
- Память: ~200-300 MB
- Сеть: ~2 Mbps upload

### Windows PC

**Receiver:**
- CPU: ~5-10%
- Память: ~100 MB

**AI Detector:**
- CPU: ~20-30% (CPU) или ~10-20% (GPU)
- GPU: ~1-2 GB VRAM (NVIDIA)
- Память: ~500 MB
- FPS обработки: 5-10 fps

**Streamer:**
- CPU: ~15-25% (кодирование x264)
- Память: ~200 MB
- Сеть: ~2.5 Mbps upload

**Общее:**
- CPU: ~40-65% (зависит от GPU)
- Память: ~800 MB - 1 GB
- Сеть: ~5 Mbps total

## Масштабирование

### Для нескольких камер
- Каждая камера → отдельный SRT поток
- Отдельные экземпляры Receiver для каждого потока
- Общий AI Detector может обрабатывать все потоки (или отдельный для каждого)
- Отдельные Streamer для каждого потока

### Для более высокой производительности AI
- Использовать более мощную GPU
- Увеличить разрешение AI входа (но снизится FPS)
- Использовать TensorRT для оптимизации YOLOv8

## Безопасность

- SRT поток не шифруется (для локальной сети нормально)
- Twitch RTMP использует защищенное подключение
- Stream key хранится в config.yaml (не коммитить в git!)

## Отказоустойчивость

- Если AI детектор падает, стрим продолжается (без оверлея)
- Если receiver теряет соединение, streamer продолжает работу (пустые кадры)
- Если streamer падает, receiver и AI продолжают работу (но стрим прерывается)
