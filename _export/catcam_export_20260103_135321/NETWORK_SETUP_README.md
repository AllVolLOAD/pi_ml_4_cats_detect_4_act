# Настройка прямого Ethernet подключения Raspberry Pi к ноутбуку

## Шаги подключения

### 1. Подключение кабеля
- Один конец патч-корда подключите к Ethernet порту Raspberry Pi
- Второй конец патч-корда подключите к Ethernet порту ноутбука

### 2. Настройка статического IP на ноутбуке (Windows)

1. Откройте "Параметры сети":
   - `Win + I` → Сеть и Интернет → Изменить параметры адаптера
   - Или: Панель управления → Сеть и Интернет → Центр управления сетями → Изменение параметров адаптера

2. Найдите ваш Ethernet адаптер (обычно называется "Ethernet" или "Подключение по локальной сети")

3. Правой кнопкой мыши → Свойства

4. Выберите "IP версии 4 (TCP/IPv4)" → Свойства

5. Выберите "Использовать следующий IP-адрес" и введите:
   - **IP-адрес**: `192.168.1.1`
   - **Маска подсети**: `255.255.255.0`
   - **Шлюз по умолчанию**: оставьте пустым
   - **Предпочитаемый DNS-сервер**: можно оставить пустым или `8.8.8.8`

6. Нажмите OK во всех окнах

### 3. Запуск Raspberry Pi

1. Вставьте microSD карту в Raspberry Pi
2. Подключите питание к Raspberry Pi
3. Подождите 2-3 минуты для загрузки системы

### 4. Подключение по SSH

Откройте PowerShell или командную строку на ноутбуке и выполните:

```bash
ssh pi@192.168.1.100
```

По умолчанию:
- **Логин**: `pi`
- **Пароль**: `raspberry`

При первом подключении появится предупреждение о fingerprint - нажмите `yes`.

### 5. Проверка подключения

Если SSH не работает, проверьте:

1. **Проверка связи** (ping):
   ```powershell
   ping 192.168.1.100
   ```
   Если ping не проходит, проверьте кабель и настройки IP.

2. **Проверка SSH на Pi** (если есть доступ к другому интерфейсу):
   ```bash
   sudo systemctl status ssh
   ```

3. **Проверка IP адреса Pi** (если есть доступ):
   ```bash
   ip addr show eth0
   ```

## Важные заметки

- IP-адрес Raspberry Pi настроен как: **192.168.1.100**
- IP-адрес ноутбука должен быть: **192.168.1.1**
- Подсеть: **192.168.1.0/24**

## После успешного подключения

После первого подключения рекомендуется:

1. Изменить пароль пользователя pi:
   ```bash
   passwd
   ```

2. Обновить систему:
   ```bash
   sudo apt update && sudo apt upgrade -y
   ```

3. (Опционально) Настроить WiFi для более удобного доступа в будущем
